hekit 1.0.0 es el primer release estable del configurador de escritorio para el teclado AULA MINI 60 HE PRO en Linux. Habla el protocolo HID del driver oficial y guarda o carga la configuración en JSON.

**Descarga hekit:** [AppImage](https://github.com/don-linux/ultra-he/releases/download/v1.0.0/hekit-v1.0.0-x86_64.AppImage) · [.deb](https://github.com/don-linux/ultra-he/releases/download/v1.0.0/hekit-v1.0.0-x86_64.deb) · [.rpm](https://github.com/don-linux/ultra-he/releases/download/v1.0.0/hekit-v1.0.0-x86_64.rpm) · [.tar.gz](https://github.com/don-linux/ultra-he/releases/download/v1.0.0/hekit-v1.0.0-x86_64-unknown-linux-gnu.tar.gz)

Los paquetes necesitan glibc 2.39 o más nuevo: Ubuntu 24.04, Debian 13, Fedora 40 o posterior. Los SHA-256 están en `checksums.txt`.

- **AppImage**, para probarlo sin instalarlo: `chmod +x hekit-v1.0.0-x86_64.AppImage` y ejecútalo. La regla udev va dentro del AppImage; cópiala a `/usr/lib/udev/rules.d/70-hekit.rules`, ejecuta `sudo udevadm control --reload-rules` y `sudo udevadm trigger --subsystem-match=hidraw`.
- **Debian y Ubuntu:** `sudo apt install ./hekit-v1.0.0-x86_64.deb`. Instala la regla udev y la recarga.
- **Fedora:** `sudo dnf install ./hekit-v1.0.0-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` con el mismo archivo). Instala la regla udev y la recarga.
- **tar.gz:** el binario, el `.desktop` y `udev/70-hekit.rules`. La regla hay que copiarla a mano, igual que en el AppImage.

Si el cable y el receptor están conectados a la vez, hekit usa el cable. Si el teclado ya estaba enchufado, desconéctalo y vuelve a conectarlo una vez para que el permiso aplique al dispositivo que ya estaba abierto.

Comprueba la instalación sin abrir la ventana:

```sh
hekit --check
```

## Added

- **Actuación por tecla y Rapid Trigger**, con presión y liberación separadas, y los ocho ejes del driver más el perfil Jade Ultra. Jade Pro usa el id 2 con tope de 3.30 mm. Jade Ultra no tiene id en el firmware: se guarda como el id 2 y el deslizador no pasa de 3.20 mm.
- **Capa normal y capa Fn**, SOCD, rapid snap, DKS, mod-tap, toggle y macros.
- **Luz guardada en el teclado** y color por tecla. No anima luces en tiempo real.
- **Tasa de informe, suspensión, zonas muertas, estabilidad y calibración adaptativa.**
- **Paquetes de Linux x86-64.** El `.deb` y el `.rpm` copian la regla udev a `/usr/lib/udev/rules.d/70-hekit.rules` y la recargan. El AppImage y el tar.gz traen la regla para copiarla a mano.

No envía reset de fábrica, entrada a flash ni la calibración que borra la calibración guardada. El PID `80B2` se reconoce y no se escribe: no hay una captura de ese hardware.
